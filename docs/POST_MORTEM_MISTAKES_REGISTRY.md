### 1. 데일리 챌린지 클리어 시 `recordDailyCompletion` 누락 버그
*   **증상**: 일일 도전 과제를 클리어하는 순간 `ReferenceError: recordDailyCompletion is not defined` 발생하며 게임 종료 처리 중단.
*   **근본 원인**: `useSudokuGame.js` 훅 내부에서 달력 완료 함수를 호출하고 있었으나, 파일 상단에 `import` 구문이 누락됨.
*   **적용된 해결책**:
    *   `src/utils/dailyChallenge.js`로부터 `recordDailyCompletion`을 정확한 인자 시그니처 `(activeDailyDateKey, timerSeconds, mistakes)`로 import 및 연결.

### 2. 게임 오버(3회 실수) 시 전적 누락으로 인한 전적·IQ 왜곡
*   **증상**: 게임에서 패배해도 `gamesPlayed`가 올라가지 않아, 한 판도 안 이겼는데 승률 100%가 나오거나 IQ 수치가 비정상적으로 치솟는 버그.
*   **근본 원인**: `storage.js`에 승리 기록 함수(`recordGameWin`)만 있고, 패배 기록 함수(`recordGameLoss`)가 설계 단계에서 누락됨.
*   **적용된 해결책**:
    *   `storage.js`에 `recordGameLoss(level, time, mistakes)` 함수를 신설.
    *   3회 실수 초과로 게임 오버 발생 시 즉시 `recordGameLoss()`를 호출하여 `gamesPlayed` 카운트를 정상 누적.
*   **평가**: ⭐️ **[Good Method - 100% 확실함]** ➔ 승/패 모든 분기에서 전적 DB가 완벽하게 동기화됨.

### 3. 메인 로비 난이도 칩 선택 시 저장된 게임이 덮어씌워지는 문제

*   **근본 원인**: 난이도 칩 클릭 핸들러가 내부적으로 `startNewGame(level)`을 동시 트리거하여 `localStorage`의 `suidoku_saved_game_v1`을 덮어씀.
*   **적용된 해결책**:
    *   `resumeSavedGame()` 전용 복원 함수를 분리하여, 홈에서 어떤 난이도 칩을 눌렀든 상관없이 기존 세이브 보드, 타이머, 실수 횟수, 메모 데이터를 100% 온전히 복구하도록 상태 머신 개선.

3. **글로벌 시간 벤치마크 랭킹 (`question_time_map.json`)**:
   * 각 퍼즐 난이도별로 전 세계 유저들의 4단계 풀이 시간(S/A/B/C 등급)을 맵핑하여 정밀한 두뇌 스코어 및 랭크 부여.

### 3. 🎨 시각적 집중도 & 게이미피케이션 (Gamification & Retention)
1. **키패드 집중도 계층 (Keypad Focus Hierarchy)**:
   * 선택된 번호는 로얄블루 점등 + 3D 확대, 미선택 번호는 55% 반투명 감광 처리하여 시선 분산 방지.
