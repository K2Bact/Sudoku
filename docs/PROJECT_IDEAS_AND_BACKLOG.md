## 🚨 [필수 최종 체크리스트] 출시 직전 실제 상용 키/DB 전환 목록 (Pre-Release Critical Gates)

> 유저님께서 **"정식 출시하자"** 또는 **"프로덕션 배포하자"**라고 말씀하실 때 **1순위로 상기 및 전환 작업을 진행하는 4대 핵심 게이트**입니다.

### 1. 📢 Google AdMob 실제 광고 단위 ID 교체 (`src/services/admobService.js`)
* **내용**: 현재 개발/테스트 중 계정 정지(Self-Click 제재) 방지를 위해 적용된 **Google 공식 테스트 광고 ID** ➔ 실제 Google AdMob 콘솔에서 발급받은 **실제 앱 ID 및 광고 단위 ID(배너, 전면, 보상형)**로 최종 교체.
* **현재 상태**: 테스트 ID 적용 중 (정식 배포 직전 교체 대기).

### 2. 🏆 순위표 하위 랭커 데이터 및 실시간 글로벌 집계 (`src/services/leaderboardService.js`)
* **내용**: 현재 인원 부족 시 2~50위를 자연스럽게 채워주는 가상 벤치마크 랭커 데이터를 실제 실시간 글로벌 데이터로 완전 동기화.
* **현재 상태**: 하이브리드 가상 랭커 적용 중 (클로즈드 테스트 후 전환 대기).

### 3. 💳 광고 제거 PRO ($2.99) 구글 인앱 결제(IAP) 상품 연결 (`src/components/RemoveAdsScreen.jsx`)
* **내용**: 현재 로컬 결제 시뮬레이션(클릭 시 즉시 무광고 전환) ➔ Google Play Console에 인앱 상품(`remove_ads_pro`, $2.99 / ₩3,900) 등록 후 실제 결제 결제 플러그인 연결.
* **현재 상태**: 로컬 결제 시뮬레이션 적용 중 (콘솔 인앱 상품 생성 후 연동).

### 4. 🎮 Google Play Games 리더보드/업적 추가 ID 매핑 (`src/services/playGamesService.js`)
* **내용**: 
  * 현재 메인 종합 순위표인 **`SUDOKU IQ`는 실제 ID(`CgkIsvv_0f4TEAIQAQ`)로 연동 완료**.
  * 향후 클래식 스피드런 / 타임어택 등 추가 리더보드 및 업적 ID를 구글 콘솔에서 생성 시 실제 ID로 매핑.
* **현재 상태**: `SUDOKU IQ` 실 ID 연동 완료, 나머지 안전 플레이스홀더 처리.

## 📋 [카테고리 1] 조작성 & 하드웨어 확장 (Input & Hardware Integration)

### 💡 1-1. 물리 / 블루투스 외장 키보드 & 키패드 완벽 지원 (Hardware Keyboard Support)
* **제안 내용**: 태블릿, DeX 환경, 스마트폰에 블루투스 키보드/외장 넘버패드를 연결해 플레이하는 프로 유저들을 위한 하드웨어 키 매핑.
* **키 매핑 스펙**:
  * `[1 ~ 9]`: 선택된 셀에 즉시 숫자 입력 / 고정입력 모드 시 숫자 전환
  * `[↑ ↓ ← →]` / `[W A S D]`: 81칸 보드 내 커서 자유 이동
  * `[Backspace]` / `[Delete]`: 선택 셀 지우기 (Erase)
  * `[N]`: 연필 메모(Notes) 모드 토글
  * `[F]`: 빠른 입력 / 고정 입력(Fast Entry) 모드 토글
  * `[U]` 또는 `[Ctrl + Z]`: 실행 취소 (Undo)
  * `[H]`: 힌트 (Hint) 요청
  * `[Space]`: 일시정지 (Pause)
  * `[Esc]` 또는 `[물리 뒤로가기 키]`: 화면 좌상단 뒤로가기 버튼과 동일하게 **게임 중단 확인 팝업**을 띄워 돌발 종료 방지.
* **현재 상태**: 구현 대기 중 (즉시 구현 가능).

## 📋 [카테고리 2] 🎨 브랜드 스플래시 & 인트로 애니메이션 (Splash Screen & Studio Logo)

### 💡 2-1. 스튜디오 로고 인트로 & 브랜드 스플래시 로딩 스크린 (App Splash & Studio Logo Intro)
* **제안 내용**:
  * 앱 최초 실행 시 브랜드/스튜디오 로고(예: Studio / Indie Lab 워터마크 또는 수제작 로고)와 함께 미려한 펄스/스도쿠 보드 생성 인트로 애니메이션을 연출한 뒤 메인 홈으로 부드럽게 페이드인 진입하는 프리미엄 스플래시 스크린.
  * 퍼즐 장르 특유의 지적이고 미려한 미니멀 브랜딩 구축.
* **현재 상태**: 백로그 영구 보관 (회사/스튜디오 브랜드명 및 로고 확정 시 구현).

## 📋 [카테고리 3] 🛡️ 구글 플레이 보안 및 게이밍 확장 (Google Play Security & Sidekick)

### 💡 3-1. 구글 플레이 앱 자동 무결성 보호 활성화 (Automatic Protection / Play Integrity)
* **제안 내용**: 구글 플레이 콘솔의 클라우드 기반 자동 위변조 방지(Anti-tampering), 불법 복제(Mod APK) 및 순위표 치팅 방지 보안 기능 켜기.
* **적용 시점**: 정식 프로덕션 배포 전 구글 콘솔에서 [Get started] 클릭하여 원클릭 활성화.
* **현재 상태**: 백로그 등록 완료 (출시 준비 단계에서 활성화).

### 💡 3-2. Play 게임즈 사이드킥 연동 (Add Play Games Sidekick to your game)
* **제안 내용**: 게임 플레이 중 구글 플레이 전용 오버레이 어시스턴트(리더보드, 업적, 플레이어 프로필, 화면 녹화/공유 등)를 앱 위에 띄워주는 Google Play Games Sidekick 연동.
* **적용 시점**: 클로즈드 테스트 또는 정식 출시 단계에서 설정.
* **현재 상태**: 백로그 등록 완료.
