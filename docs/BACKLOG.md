## 2. 결정할 것

**DISC-1 해외 홍보에 돈·시간을 쓸까.** 국가 6개(한국·독일·미국·인도·일본 + 사우디 2026-10-07 검토 제출) 타겟팅·13개 언어 등록정보·출시 — 유통은 막힌 곳이 없다.
국가별 설치 수는 **지금 모른다**(09-22 무렵 수치를 옮겨 적었던 것을 09-30 에 정정). 판단하려면 콘솔 통계를 새로 본다.
미국·일본 스도쿠는 경쟁이 가장 심한 칸. 코드로 푸는 문제가 아니다 — 제목·짧은 설명 키워드, 스크린샷 첫 장, 결국 광고.

**BILL 광고 제거를 팔까** (R-1·R-5). 판매자 계정 준비는 끝(정산 계좌·15% 수수료·W-8BEN). 상품은 없고 앱은 판매 버튼을 숨긴다.
켜려면:
- **플러그인 선택** — `@capgo/native-purchases`(무료, Capacitor 8 과 버전이 같이 감, 추천) · RevenueCat(구독·서버용, 월 매출 $2,500 초과분 1%) ·
  cordova-plugin-purchase. 지금 코드(`playBillingProvider.js`)는 **없는 패키지**(`@capacitor-community/in-app-purchases`, npm 404) 기준이라 다시 써야 한다.
- **순서가 고정** — ① 플러그인 설치·결제 코드 재작성 ② BILLING 권한이 병합 매니페스트에 들어갔는지 ③ 그 빌드를 업로드(그래야 콘솔이 상품 생성을 연다)
  ④ 일회성 상품 `remove_ads_permanent` 생성(**ID 영구 불변**)·비소비성·가격·**활성화**(빠뜨리면 상품이 없는 것처럼 보인다)
  ⑤ `VITE_BILLING_PROVIDER=play` 로 다음 빌드 ⑥ 라이선스 테스터로 실제 구매 확인. 업로드 두 번, 순서 못 바꿈.
- **일본** — 판매 국가에서 뺄지, 특정상거래법 표기가 필요한지.
- **통신판매업 신고** — 지금은 면제(직전 연도 거래 50회 미만). 사업자등록이 일반과세자라 면제 근거는 이것 하나 — 연 50회를 넘기면 신고.
- 가격은 코드가 만들지 않는다(스토어 문자열을 그대로).
- **PR-1 Play 자동 보호를 같이 켠다** (옛 R-4, 사용자 2026-10-01: "유료 상품 출시 때 같이"). 스토어 밖에서 받은 설치(광고 뗀 개조 APK 등)가
  "플레이에서 받으세요" 로 막힌다 — 파는 기능을 개조판이 공짜로 푸는 것을 막는 장치라, 팔 것이 생길 때 켠다. 코드 변경 없음, 켠 뒤 올리는 번들부터 적용.
  위치: 콘솔 사이드바 「Google Play로 보호됨」 → 자동 보호 → 시작하기 (2026-09-17 화면: 꺼져 있음).
  켜기 전에 확인: ① 내부 앱 공유·테스트 트랙 설치 ② 삼성 스마트 스위치로 폰을 옮긴 사용자(플레이를 거치지 않고 옮겨진 설치)가 막히지 않는지
  ③ 디버그 실기 설치(USB)는 플레이를 안 거쳐 영향 없을 것 — 확인만.

**D10-1 1v1 「상대 없음」 카드 문장** — 「다시 찾기」 버튼을 넣었지만(Diary 102) 문장은 아직 「…AI와 대전할까요?」. 두 버튼에 맞게 고칠지.

- **🚫 AdMob 앱 단위 게재빈도 설정을 켜지 말 것.** 전면과 **보상형**에 같이 걸리고, 걸리면 부활·힌트 충전 버튼이 아무 말 없이 안 된다.
  전면 빈도는 코드가 이미 막는다. 반영이 최대 24시간 늦어 바로 안 보인다. (2026-09-17 저장 직전에 취소)
- **위치 권한을 추가하는 순간 광고 SDK 가 대략 위치를 자동 수집한다**(구글 공지 2026-09-12). 지금은 병합 매니페스트에 위치 권한 0.
  추가하게 되면: 데이터 보안 "위치 예" · 개인정보처리방침 · 원치 않으면 SDK 플래그로 끄기. 1v1 은 위치를 안 쓴다(난이도·티켓 신선도만).
- **일본 상표** — 「数独 / Sudoku」 는 니콜리 등록(9류 포함)이라 일본에선 「ナンプレ」. X-Wing 은 루카스필름 9류 등록이 있지만 **기법 이름이라 유지**(사용자 결정).
- **문구가 코드 조건과 맞는지는 게이트가 없다**(C-5) — 뜻을 읽어야 해서. 새 업적·문구는 13개 언어를 사람이 본다(예: 「5전 5승」 인데 조건은 5승).
- **일본어 한자 21종**(构→構 등, 2026-09-11 에 내가 판정)은 원어민 확인 없이 남아 있다. ChatGPT 일본어 검수는 종료(사용자 2026-09-28).
- **광고는 릴리스에서 실제 단위**(18 부터), 디버그 APK 만 샘플. 스토어 설치본의 광고는 누르지 않는다 — 자세한 건 AGENTS §3·RELEASE_STATE.
- **저장소를 공개로 바꾸기 전에 git 이력부터 정리.** 경쟁 앱 리뷰 원문(`docs/research/reviews/raw/`, 남이 쓴 글 20개)은 지금 파일에서는 뺐지만
