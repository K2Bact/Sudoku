## 왜 통합했나

`PROJECT_IDEAS_AND_BACKLOG.md` 의 "출시 직전 필수 게이트" 4개 중 **3개가 이미
해결됐는데도 "대기 중" 으로 적혀 있었습니다.** 코드를 직접 확인하고 알았습니다.

| 문서가 말한 것 | 실제 코드 |
|---|---|
| AdMob 테스트 ID 교체 대기 | 테스트 ID 테이블 자체가 없음. `.env` 한 줄로 전환 |
| 가상 랭커 → 실제 데이터 전환 대기 | 이미 백분위 라벨(`TOP 0.1%`)로 교체됨 |
| Play 게임즈 "나머지 안전 플레이스홀더" | 플레이스홀더 없음. 실제 ID 하나 + 정직한 no-op |

**끝난 일이 "대기 중" 으로 남아 있으면, 다음에 읽는 사람이 없는 일을 하려 듭니다.**
그래서 이 파일에는 **코드로 확인한 상태만** 적습니다. 확인하지 않은 것은 "미확인" 이라고
적습니다.

## 🔴 출시 전 반드시 (Release Blockers)

### R-1. 인앱 상품 생성 — **사용자만 할 수 있음**

Play Console 작업이라 Claude/Gemini 가 대신할 수 없습니다.

1. Play Console → 수익 창출 → 인앱 상품 → **관리형 상품** 생성
2. **상품 ID 를 정해야 합니다. 한 번 만들면 영원히 못 바꿉니다.**
   - 코드의 현재 값: `remove_ads_permanent` (`src/billing/index.js`)
   - 옛 문서의 값: `remove_ads_pro`
   - **어느 쪽으로 정하든 코드를 그 값에 맞추면 됩니다.** 아직 Console 에
     아무것도 만들지 않았으므로 지금이 자유롭게 정할 마지막 시점입니다.
3. 가격 설정 — 기본 가격 하나를 정하면 구글이 나라별로 환산하고 현지 관습에 맞게
   다듬습니다(₩3,873 대신 ₩3,900). 개별 국가만 따로 덮어쓸 수도 있습니다.
4. 활성화

> **코드는 가격을 만들지 않습니다.** 스토어가 주는 문자열을 그대로 씁니다.
> 나라마다 통화·기호·구분자·위치가 다르고 구글이 이미 답을 알고 있습니다.
> 직접 조립하려던 것이 `"영구 제거하기 ({price})"` 가 화면에 찍힌 원인이었습니다.

### R-2. 결제 활성화 — 상품 생성 후

```
npm i @capacitor-community/in-app-purchases && npx cap sync
.env 에 VITE_BILLING_PROVIDER=play
```
자리 코드는 한 줄도 바뀌지 않습니다. `src/billing/playBillingProvider.js` 가
완성돼 있고 잠들어 있습니다(상품 조회·구매·소유 확인·acknowledge·복원).

### R-3. 광고 활성화 — 실제 출시 시점

```
npm i @capacitor-community/admob && npx cap sync
.env 에 VITE_ADMOB_BANNER_ID / _INTERSTITIAL_ID / _REWARDED_ID
.env 에 VITE_ADS_PROVIDER=admob
```
**클로즈 테스트 중에는 절대 켜지 마세요.** 우리 기기에서 발생하는 노출·클릭은
invalid traffic 이고 그것이 AdMob 계정이 정지되는 경로입니다.

### R-4. Play Integrity 자동 보호 — **사용자만 할 수 있음**

Play Console → 앱 무결성 → 자동 보호 → `시작하기`.
**코드 변경 없음.** 구글이 출시 번들에 위변조 방지를 입혀줍니다.

## 🟠 출시 후 / 여유 있을 때

### O-1. Play 게임즈 리더보드·업적 추가

현재 상태(코드로 확인):
- `LEADERBOARD_IDS` = `{ BRAIN_IQ: 'CgkIsvv_0f4TEAIQAQ' }` — 실제 ID 하나
- `ACHIEVEMENT_IDS` = `{}` — 비어 있음
- `submitScore()` 는 `no_leaderboard_for_mode` 를, `unlockAchievement()` 는
  `not_configured` 를 정직하게 반환. **가짜 성공을 보고하지 않습니다.**

추가하려면 Console 에서 리더보드/업적을 만들고 그 ID 를 위 두 표에 넣으면 됩니다.
표가 비어 있는 동안은 호출이 안전한 no-op 입니다.

### O-2. Play 게임즈 사이드킥

게임 위에 뜨는 구글 플레이 오버레이(리더보드·업적·프로필·녹화·공유).
Console 설정. **출시 필수 아님.**

> **미확인:** 구글이 Play Games 기능을 자주 개편해서 사이드킥의 현재 형태·가입
> 조건·지원 국가는 확인되지 않았습니다. 콘솔의 실제 화면을 보고 판단하세요.

### O-3. 외장 키보드 지원 (태블릿 / DeX)

옛 문서에 "즉시 구현 가능" 으로 적혀 있던 항목. 키 매핑 스펙:

| 키 | 동작 |
|---|---|
| `1`~`9` | 선택 셀에 숫자 입력 / 고정입력 모드에서 숫자 전환 |
| `↑↓←→` / `WASD` | 보드 커서 이동 |
| `Backspace` / `Delete` | 선택 셀 지우기 |
| `N` | 메모 모드 토글 |
| `F` | 빠른 입력 모드 토글 |
| `U` / `Ctrl+Z` | 실행 취소 |
| `H` | 힌트 |
| `Space` | 일시정지 |
| `Esc` | 게임 중단 확인 팝업 (뒤로가기와 동일) |
