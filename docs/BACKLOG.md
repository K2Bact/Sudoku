## 2. 결정할 것

**DISC-1 해외 홍보에 돈·시간을 쓸까.** 배포 6개국(한국·독일·미국·인도·일본·사우디) · 13개 언어 등록정보 — 유통은 막힌 곳이 없다.
국가별 설치 수는 지금 모른다(콘솔 통계를 새로 봐야 한다). 2026-10-07 ASO: 대표 검색어에서 우리는 30위 밖, 제목·간단한 설명을 새로 등록(D12 로 재측정).

**BILL 광고 제거를 팔까** (R-1·R-5). 판매자 계정 준비는 끝(정산 계좌·15% 수수료·W-8BEN). 상품은 없고 앱은 판매 버튼을 숨긴다. 켜려면:
- **플러그인** — `@capgo/native-purchases`(무료, 추천) · RevenueCat · cordova-plugin-purchase. 지금 `playBillingProvider.js` 는 없는 패키지 기준이라 다시 써야 한다(D2).
- **순서 고정, 업로드 두 번** — ① 플러그인·결제 코드 ② 병합 매니페스트에 BILLING 권한 ③ 그 빌드 업로드(콘솔이 상품 생성을 연다)
  ④ 일회성 상품 `remove_ads_permanent`(**ID 영구 불변**)·비소비성·가격·**활성화** ⑤ `VITE_BILLING_PROVIDER=play` 로 다음 빌드 ⑥ 라이선스 테스터로 구매 확인.
- **일본** 판매 여부·특정상거래법 표기 · **통신판매업 신고**는 지금 면제(연 50회 미만), 넘기면 신고 · 가격은 스토어 문자열 그대로.
- **PR-1 Play 자동 보호를 같이 켠다**(사용자 2026-10-01) — 스토어 밖 설치(개조 APK)를 막는다. 콘솔 「Google Play로 보호됨」 → 자동 보호.
  켜기 전 확인: 내부 앱 공유·테스트 트랙 설치 · 스마트 스위치로 옮긴 설치 · USB 디버그 설치.

**D3 레벨별 순위표를 만들까** (O-1). 클래식·스피드런 Lv.1~5 리더보드 10개를 **사용자가 콘솔에서 먼저** 만들어야 시작할 수 있다
(시간 기록이라 「낮은 점수부터」, 게시 후 변경 불가). 지금 순위표는 Logic Score 하나. 만들면: ID 를 `LEADERBOARD_IDS` 에, `submitScore` 를 실제 전송으로,
버튼이 현재 탭의 순위표를 열게. Play 게임즈 설정은 앱과 따로 게시.

**C-4 AdMob 판매자 정보(sellers.json) 공개.** 지금 「기밀」. 공개하면 일부 광고주 수요가 붙지만 개발자명이 공개 목록에 남는다. 수익 데이터가 쌓인 뒤 정한다.

**STORE 스토어 그림 7개 언어** — es·fr·it·pt·ru·zh-CN·zh-TW 의 스크린샷·피처 그래픽이 옛것(「Sudoku IQ 100」·옛 규격). 피처 그래픽은 "그 나라 출시 때"(STORE-2).
