# 세션 목차 — 어느 대화에서 무엇을 했나

**새 세션은 이 파일을 다 읽지 않는다.** 시작은 `AGENTS.md` → `docs/BACKLOG.md` 의 「현재 상태」.
이 파일은 「그 얘기 어디서 했지?」 를 찾을 때만 — 세션 이름과 Diary 번호를 알려 주고, 내용은 Diary 에 있다.

**쓰는 규칙** (사용자 2026-10-13: 세션이 길어지면 토큰이 늘어 작업 단위로 새 세션을 열기로)
- 세션을 닫을 때 한 줄만 더한다: 이름 · 날짜 · Diary 번호 · 주제. 대화를 요약하지 않는다 — 결정과 이유는 Diary, 할 일은 BACKLOG 에 이미 있다.
- 세션 원문을 다시 볼 일은 거의 없다. 사용자의 말은 Diary 가 인용해 둔다. 꼭 원문이 필요하면 앱의 세션 목록에서 이름으로 연다.
